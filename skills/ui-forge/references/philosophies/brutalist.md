# Brutalist

The web before the polish: raw, functional, honest, loud. Structure
shown, not decorated.

## Principles

- Function over form, and it shows: borders are 2 px, edges are square,
  components are obviously components.
- Visual honesty: a list is a list (border rows), a button is a button
  (rectangle), nothing pretends to be glass.
- Default browsers (black text, blue link) are allowed and even loved —
  anatomy that ships without theme is a feature of this direction.

## Structure

- Explicit: outlined boxes, hard dividers, asymmetric grids that admit
  their asymmetry.
- Navigation can be a list of links — no dropdown dressing.

## Visual treatment

- High contrast, near-black text, border-first surfaces, no shadows or
  minimal linear ones.
- Imagery straight: duotone, hard crops, no rounded-corner softening.
- The "rambow" accent works if used sparingly; classic version = stark
  two-tone + one warning color for the action.

## Typography and palette

- System monospace or a grotesk at large weight works; mix title case
  with mono tags (convention of the tribe).
- Palette: white/off-white, near-black, one or two signal colors.

## Microinteractions

- Snap: 60–120 ms, hard easing (linear or near), hover = color swap or
  underline — not translation with an ease-out glamour.
- Drag/click affordances: default element press states are fine,
  honest and cheap.

## Dials (1–10)

- `variance`: 4–7 (asymmetric layouts, but each asymmetrical tile carries
  meaning, not noise)
- `motion`: 1–2 (brisk, no long waits)
- `density`: 6–9 (it wants to pack information)

## Performance cost

- Very low. No webfont needed (system stack), no shadows, no image
  treatments, CSS-only. Strong at 30–50 KB critical.

## Works best when

- A tool for professionals (devtools, dashboards, terminal), an art/
  wip/design-brand "anti-corporate" play, or a statement that
  seriousness > appearance.

## Avoid when

- Consumer retail of warmth (a temperamental loud style at checkout
  cross-signals).
- Brand needs "premium feel" via luxury cues (brutalism reads
  deliberate-rough).
- Any audience that expects discoverability-by-design — signposting is
  raw here and must be exceptional.
